# Seção 8 - Explorando e entendendo o Github

## Aula 74 - Criando repositório

- É possível criar repositórios na interface do github
- Ao inicializar, preenchemos algumas informações importantes:
  - Nome, descrição, licença, etc
- Tudo isso pode ser alterado depois se necessário

## Aula 75 - Verificando código fonte e licenças

- Aba code da acesso a informações importantes como:
  - o código fonte
  - README.md
  - Licença do projeto
  - criar branches
  - adicionar arquivos, e muito mais

### Aula 76 - Criando e verificando issues

- Aba issues permite criar tarefas ou possíveis bugs do projeto
- Importante para manter a organização do que precisa ser feito e corrigido
- Podemos usar markdown no texto, e normalmente há um padrão para a criação de issues
- a issue deve possuir um label e um responsável

## Aula 77 - Atualizando projeto por pull request

- Aba pull request é onde os colaboradores enviam código para resolver as issues ou adicionar novas funcionalidades ao projeto
- A ideia é que o código não seja inserido direto na main, e sim passe por um pull request para ser analisado
- O pull request vem de uma nova branch e enviado para o repo com o incremento de código

## Aula 78 - Processos CI/CD no Github

- Aba actions é onde se cria as automatizações de deploy com integração em outros serviços
- Incluindo CI/CD (Continuous Integration/Continuous Development)
- permite criar uma rotina de atualizações da main automaticamente, e outros processos

## Aula 79 - Criando projetos no Github

- Aba projects permite criar um projeto e utilizar um quadro de tarefas
- Processo conhecido como Kanban, ajuda a organizar, criando notas que podem virar issues
- Estrutura indicada: Backlog, retorno de qualidade, desenvolvimento, teste, finalizadas

## Aula 80 - Criando uma Wiki no Github

- Aba wiki permite criar uma documentação mais extensa para o projeto
- Permite descrever funcionalidades, bugs conhecidos e não solucionados, entre outras funções
- A ideia é funcionar como um repositório de conhecimento sobre o projeto

## Aula 81 - Visualizando os dados do projeto

- Aba insights permite ter informõesdetalhadas do projeto como:
  - Quem são os contribuidores
  - Commits
  - Forks, e muito mais
- é interessante para entender como o projeto está andando e a sua evolução desde o início

## Aula 82 - Configurações do repositório

- Aba settings da acesso a diversas configurações do projeto
- Permite:
  - alterar o nome do repo
  - remover ou adicionar features
  - adicionar colaboradores
  - apagar o repositório

## Aula 83 - Criando gists

- gists são pequenos blocos de códigos que podem ser hospedados no Github
- O link do gist pode ser compartilhando
- Gist se assemelham bastante a repositórios

## Aula 84 - Buscando repositórios interessantes

- Github não ser só para salvar projetos, também podemos encontrar repos interessantes
- Podemos aprender olhando o código fonte de desenvolvedores experientes
- Podemos dar star em projetos que gostamos ou fork para continuar o projeto em um repo próprio
