## 📌 Sobre o curso

Curso da **Udemy** com abordagem prática, em que todos os comandos e recursos são explicados como são usados no dia a dia de um desenvolvedor. A proposta é que, ao final, o aluno esteja apto a usar o Git profissionalmente.

**O que o curso oferece:**

- Git aplicado à prática de um dev, dos comandos fundamentais aos mais avançados
- GitHub completo: Issues, Pull Requests, Code Review, Wiki, Projetos e mais
- Criação de gists para compartilhamento de código
- Desenvolvimento de um portfólio com o GitHub Pages
- Criação de documentos de texto com Markdown

Além do controle de versão para projetos de software, o curso leva à criação de um portfólio hospedado gratuitamente nos servidores do GitHub.
