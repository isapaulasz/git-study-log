## 📌 Sobre o curso

Curso da **Udemy**, criado pela **Omni Academy**, que ensina para que servem o Git e o GitHub e como usá-los em projetos pessoais, de forma leve, descomplicada e prática. O curso explica os porquês e como essas ferramentas permitem controlar as versões de um software.

**O que o curso propõe:**

- Ensinar os principais fundamentos de Git e GitHub, essenciais para o desenvolvimento de um projeto de software
- Aprender fazendo: criar repositórios, armazenar e atualizar projetos de forma segura em um só lugar, o GitHub, com repositórios públicos ou privados
- Dar visibilidade no mercado: manter projetos online para que qualquer pessoa possa ver o código-fonte, o que hoje é um diferencial para clientes e empresas
- Conteúdo enxuto, com os assuntos mais importantes selecionados, organizados e apresentados de forma coesa e simples
- Estrutura pensada para favorecer o aprendizado, com técnicas de aprendizagem baseadas em evidências
