## 🎓 Plataformas de estudo

### 🧑‍🏫 Udemy

A [**Udemy**](https://www.udemy.com) é uma plataforma de cursos online com videoaulas sobre diversos temas, ideal para aprender no seu ritmo e rever o conteúdo quando precisar.

📚 **Cursos:**

- *Git e GitHub Essencial para Iniciantes*: a base para começar a versionar código e colaborar no GitHub.
- *Git: do Básico ao Avançado*: aprofundamento em branches, merge, rebase, histórico e fluxos de trabalho.

📂 **Nas pastas:** anotações de cada aula e os comandos e exercícios praticados durante os cursos.

### 🌳 Learn Git Branching

O [**Learn Git Branching**](https://learngitbranching.js.org/?locale=pt_BR) é uma plataforma visual e interativa para aprender Git na prática, mostrando em tempo real como commits e branches se comportam a cada comando.

- 🌟 Níveis progressivos, do básico ao avançado
- 🌟 Visualização gráfica da árvore de commits
- 🌟 Ótimo para fixar comandos como `commit`, `branch`, `merge`, `rebase` e `cherry-pick`

📂 **Na pasta:** anotações dos níveis concluídos e os comandos praticados em cada etapa.

### 🔗 Links úteis

Uma coleção de artigos, documentações, vídeos e ferramentas que encontrei pelo caminho. Cada link vem com um breve resumo do que ele ensina.

📂 **Na pasta:** arquivos com os links organizados por tema.
